# Конструктор печати

Конструктор печати — это новый фронтовый сценарий печати и скачивания документа заказа. Старая печать и старое скачивание `.doc` остаются без изменений: они по-прежнему формируют полный документ одной кнопкой.

## Как работает сейчас

- На странице просмотра заказа есть отдельная кнопка `Конструктор печати`.
- Перед печатью открывается модалка с настройками.
- По умолчанию включено все: товары, цены, итоги, скидка, оплаты, клиент, доставка, комментарии и подписи.
- Пользователь может отключить ненужные блоки и выбрать только часть товаров.
- Из этой же модалки можно сразу выполнить печать или скачать `.doc`.
- Все настройки работают только на фронте. В базу ничего не сохраняется.

## Шаблоны

Сейчас доступны фронтовые шаблоны:

- `Полный документ` — все включено.
- `Клиенту без цен` — состав заказа без цен и финансового блока.
- `Для производства` — товары, размеры, цвет/покрытие и комментарии без клиента, доставки, цен и подписей.
- `Для доставки` — клиент, телефон, адрес и товары без цен.

При выборе шаблона заново выбираются все товары заказа, а настройки переключаются под выбранный сценарий.

## Важные правила

- Если выключить цены, автоматически выключаются итоги, скидка, оплаты и долг.
- Если выключить итоги, автоматически выключаются скидка, оплаты и долг.
- Нельзя печатать или скачивать документ без выбранных товаров.
- Если выбрана только часть товаров, сумма считается только по выбранным позициям.

## Идеи для улучшения

- Добавить предпросмотр документа прямо в модалке.
- Сохранять последний выбранный шаблон и настройки в `localStorage`.
- Дать пользователю создавать свои шаблоны.
- Добавить выбор ориентации страницы: альбомная или книжная.
- Добавить выбор плотности документа: обычная, компактная, очень компактная.
- Добавить настройку названия документа.
- Добавить режим печати нескольких версий сразу: например, клиенту без цен и производству.
- Добавить отдельные наборы колонок для разных типов товаров.
