# Конструктор печати

Конструктор на странице просмотра заказа формирует документ для печати или скачивания `.doc`. Документация сверена с кодом 2 ноября 2026 года.

## Как пользоваться

1. Открыть заказ и нажать «Конструктор печати».
2. Выбрать шаблон, товары и отображаемые блоки.
3. Нажать печать или скачивание в диалоге.

По умолчанию выбраны все товары, включены цены, итоги, скидка, оплаты, клиент, доставка, комментарии и подписи. Поставщик по умолчанию скрыт и включается отдельно. Поддерживаются все восемь типов позиций заказа.

Настройки работают на фронтенде и не сохраняются в БД. В текущем интерфейсе страницы заказа используется кнопка конструктора; отдельных кнопок старой печати и скачивания на странице нет.

## Шаблоны

- «Полный документ» — все товары и основные блоки; поставщик скрыт.
- «Для производства» — товары, размеры, цвет/покрытие и комментарии без клиента, доставки, цен и подписей.
- «Для доставки» — клиент, телефон, адрес и товары без цен, комментариев и подписей.

При выборе шаблона заново выбираются все товары. Отдельного шаблона «Клиенту без цен» нет; такой вариант настраивается отключением цен в полном документе.

## Правила

- При отключении цен выключаются итоги, скидка, оплаты и долг.
- При отключении итогов выключаются скидка, оплаты и долг.
- Для печати или скачивания нужно выбрать хотя бы одну позицию.
- Стоимость выбранных товаров считается только по выбранным позициям.
- `.doc` содержит HTML с MIME `application/msword`; это не файл OOXML `.docx`.
- В браузере документ открывается в новом окне и вызывается диалог печати после загрузки изображений. В Electron сервис открывает и фокусирует окно документа, без автоматического вызова `window.print()`.

## Основные файлы

- [print-constructor-dialog.component.ts](src/app/common/dialogs/print-constructor-dialog/print-constructor-dialog.component.ts) — настройки, шаблоны и выбор позиций.
- [print-constructor.types.ts](src/app/common/dialogs/print-constructor-dialog/print-constructor.types.ts) — типы настроек.
- [order-document-html-builder.service.ts](src/app/services/order-document-html-builder.service.ts) — HTML документа.
- [order-document.service.ts](src/app/services/order-document.service.ts) — Blob для скачивания.
- [order-print.service.ts](src/app/services/order-print.service.ts) — окно документа и печать.

Предпросмотр внутри диалога, пользовательские шаблоны и сохранение настроек между открытиями не реализованы.
