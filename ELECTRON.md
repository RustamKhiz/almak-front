# Electron desktop build

## Development

```bash
npm run electron:dev
```

This starts Angular with the `local` configuration and opens it in Electron.

## Production package

```bash
npm run electron:build
```

The Windows installer is generated in `release/`.

For a faster package check without creating the installer:

```bash
npm run electron:pack
```

## Backend URL

The desktop build uses `src/environments/environment.electron.ts`.
Change `apiBaseUrl` there before building if the desktop app should call another backend instead of `https://almakk.ru/api`.

## Auto updates

Auto updates are wired through `electron-updater` and `electron-builder`.
The update URL in `package.json` points to:

```json
"publish": [
  {
    "provider": "generic",
    "url": "https://almakk.ru/downloads/"
  }
]
```

The update server must contain the artifacts generated by:

```bash
npm run electron:publish
```

For the download button in the web app, upload or copy the latest installer to:

```text
https://almakk.ru/downloads/Almak-Setup-latest.exe
```

The GitHub Actions deploy workflow does this automatically on every frontend deploy.

Every release must have a higher `version` in `package.json`.

For production Windows releases, use a code signing certificate and remove the unsigned dev-only setting:

```json
"signAndEditExecutable": false
```
